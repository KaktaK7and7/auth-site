Что умеет Ziren Assistant

Один каталог для двух способов управления. «Змея» выполняет локальные команды по точным и пользовательским триггерам, а «Мелисса» понимает естественную формулировку через AI и передаёт в Core только разрешённое структурированное действие.

Safety model

AI не получает произвольный доступ к Windows

Мелисса выбирает только feature_id и action_id из разрешённого каталога. Core повторно проверяет действие и только после этого вызывает локальный модуль. Неизвестные действия, произвольный shell и низкая уверенность классификатора не исполняются.

Выключение, перезагрузка и спящий режим требуют отдельного подтверждения. Визуальный анализ экрана не заявляется как разрешение на произвольный клик по координатам.
